> [`phase-0-platform.md`](phase-0-platform.md) alongside 42 platform tickets
> and seven other epics. Sessions are scoped by **epic**; task files are
> organised by **phase**. Where those cross, a ticket needs one session to
> write the code and another to write its status — and work recorded in one

> Splitting the file was chosen over splitting each ticket. Nothing about the
> tickets changed in the move: same ids, same statuses, same acceptance
